GAFF parameter table (gaff_bonded.json)

Source
------
Derived from the AmberTools gaff.dat parameter file (GAFF 1.81) through the
Sobtop reference files (bonded_param.dat, LJ_param.dat).

Generation
----------
scripts/build_parameter_table.py rebuilds this file from
references/sobtop/*.dat.  The JSON provenance block records the source
SHA-256 hashes and the GAFF version.
